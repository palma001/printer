# Printer Server

## Dependencies

- `wkhtmltopdf` installed

## Running 

### Server

1. To run the server, must run the server.exe file, ensure that you have all the files on the zip. 

2. This will run the server that enables websocket to comunicate along the web app and the to keep in sync the ui local interface. 

3. If a console is open, do not close it. 

### Local interface

1. To run the local interface you have printer_ui_win.exe, this will enabling you a way to connect, disconnect or receive a clear message of any state of the process. 

2. If you close the ui is no problema as long you keep the server up.
